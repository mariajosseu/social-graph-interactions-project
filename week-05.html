    Reading the result / Limits matterWHAT THIS DOES NOT SAY

    The text underneath the claim

    A tiny description is not a tiny article.

    Spider-Man's description reads, “Spider-Man is a superhero in American comic books published by Marvel Comics.” That is 12 words beside 106 incoming links. Super Rabbit has no incoming links in this snapshot and a 36-word description. The points fit the weak overall association, but these are metadata descriptions, not measurements of full Wikipedia page length.

    The frozen node file contains short descriptions, not article bodies. This comparison can test whether graph attention predicts the length of these blurbs; it cannot answer whether famous characters have longer articles. Link counts also reflect this dataset's page-to-page references, not readership or cultural fame.

    Question 07 / The weirdest pageCOSINE × CORPUS CENTROID

    Figure 07 / Lexical outliers

    Who has the weirdest Wikipedia page?

    Here, weird means a page whose word-count vector points away from the average page. Build the centroid of all 303 unit-length vectors, then rank pages by one minus cosine similarity to it. Switch to the cleaned version, which drops reference sections and bare numbers, and inspect each winner.

    Loading the ranking...

    
				
    
				
    The leaders mostly repeat their own distinctive names (Mark Hazzard, Killebrew, Ollie, Weying) or are short pages. The ranking mostly measures name repetition and page length, not strange content. Cleaning changes little, so reference lists and formatting were not the main driver. A page is far from the centroid because it says its own name often.
